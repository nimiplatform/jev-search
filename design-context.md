# Design context — Jev Search

## Product identity
Jev Search. Jev is TypeSafe's model for selecting sources and ranking results; Search1API supplies the search engines. Use TypeSafe's official pink icon for the search results header and browser icons. Keep the builder attribution in the footer, not in the wordmark or page title. The page title and subtitle should communicate both source selection and ranking.

The homepage has no separate header or logo image: center the "Jev Search" heading above the search box, with "Picks where to search. Ranks what comes back." as the subtitle (Jev is named in the heading, so the subtitle does not repeat it). Under the search box, three plain-text example requests that look nothing alike (a phrase with a source and a time, a question with only a source, a bare topic) say "write it any way you like" without prescribing a format; no template placeholder. The footer keeps two icon-and-word links (Showcase, Community) above the rule and one credit line below it. The search results page retains its compact navigation header.

## Users
Developers and AI-curious people, many of them following TypeSafe's Jev. They arrive from a post or a link, type one question, and judge the product in the first ten seconds by whether the results look right. Desktop first, phone second.

## Brand personality
Precise · candid · quiet. It shows its judgment instead of talking about it, and it never pretends to answer ("no generated answers").

## Aesthetic direction
Visitor mode on the home page: Persuade, but the product is the proof, so the page is a Workbench: the real search box as the only call to action, then the real interface fragments as the demonstrations. Light by default (a search page lives next to the reader's other tabs). TypeSafe pink #e551ba for interface accents, dark text on filled pink controls, and deeper pink #a8207c for small brand text on light backgrounds. Surfaces are neutral with a subtle pink tint; dark surfaces use lighter pink brand text. Search result links follow the familiar convention: blue before visiting, purple after visiting, with lighter variants on dark backgrounds. One display face for the headline (Newsreader) against the system UI stack for everything a user operates. Motion only for feedback and continuity.

## Design principles
1. The interface fragment is the copy: show the chips lighting, show the percentages, write one sentence.
2. Say Jev by name where it acts: picks where to look, ranks what comes back.
3. Nothing decorative that a user could mistake for a control.
4. One credit line, once.
