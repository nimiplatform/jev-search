# Design context — s1 ask

## Users
Developers and AI-curious people, many of them following TypeSafe's Jev. They arrive from a post or a link, type one question, and judge the product in the first ten seconds by whether the results look right. Desktop first, phone second.

## Brand personality
Precise · candid · quiet. It shows its judgment instead of talking about it, and it never pretends to answer ("no generated answers").

## Aesthetic direction
Visitor mode on the home page: Persuade, but the product is the proof, so the page is a Workbench: the real search box as the only call to action, then the real interface fragments as the demonstrations. Light by default (a search page lives next to the reader's other tabs). Brand blue #007bff from the Search1API mark; everything else neutral, tinted toward the blue. One display face for the headline (Newsreader) against the system UI stack for everything a user operates. Motion only for feedback and continuity.

## Design principles
1. The interface fragment is the copy: show the chips lighting, show the percentages, write one sentence.
2. Say Jev by name where it acts: picks where to look, ranks what comes back.
3. Nothing decorative that a user could mistake for a control.
4. One credit line, once.
